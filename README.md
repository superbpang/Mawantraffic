# 馬灣船程、車程及路面

手機優先的第一版。打開頁面約三十秒內可以知道：下一班船或巴士、那個時間屬於官方實時、官方班表還是服務通告，以及相關走廊的特別交通消息、鏡頭和已核對路段的車速。

瀏覽器只向本站取資料。九巴到站、運輸署消息、閉路電視、車速、行車時間和天文台警告由伺服器轉發。渡輪、珀麗灣居民巴士和陽光巴士只有表定開出，沒有船隻或巴士位置。

## 執行

```bash
python3 server.py
```

然後開啟 <http://127.0.0.1:8080>。預設起點是馬灣、方向是離開馬灣。

```bash
python3 -m unittest tests.test_board
```

班表在 `catalog.py`，每條路線帶有來源網址、生效日期和 2026-11-21 的擷取日期。2026 年公眾假期來自香港政府一站通，頁尾修訂日期為 2025 年 5 月。

## 這一版沒有

沒有帳戶、推送、收藏或定位。沒有全港車速圖，也沒有逐步導航。青馬大橋、汲水門大橋、青嶼幹線、馬灣路和長青公路沒有可核對的車速數字，頁面只顯示消息和鏡頭。車速只顯示北大嶼山公路和西九龍公路上、該次檔案有有效車道的一個偵測器。票價不印在卡片上。
